# SCT_DA_4 - Business Insights Report (EDA)

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) to understand customer behavior, identify trends, and generate actionable business insights from the dataset.

## Objective

* Explore and understand the dataset.
* Analyze customer demographics and purchasing behavior.
* Identify patterns, trends, and relationships in the data.
* Generate meaningful business insights through visualization and statistical analysis.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

### Data Exploration

* Dataset inspection
* Data type verification
* Summary statistics generation

### Data Cleaning

* Missing value analysis
* Duplicate record verification
* Data quality checks

### Visual Analysis

* Customer income distribution
* Spending patterns analysis
* Product category analysis
* Purchase channel comparison
* Campaign response analysis

## Key Insights

* Customers with higher income tend to spend more overall.
* Web purchases are higher than catalog purchases, indicating strong online engagement.
* Wine and meat products contribute significantly to customer spending.
* Campaign response rates are relatively low, suggesting opportunities for better targeting.
* High-value customers can be targeted through personalized marketing strategies.

## Outcome

The analysis provided valuable insights into customer purchasing behavior and marketing effectiveness. These findings can help businesses improve customer targeting, optimize marketing campaigns, and enhance decision-making.
